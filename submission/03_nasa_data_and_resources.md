# NASA data and resources used

| Resource | How we used it | Link |
|---|---|---|
| FIRMS: Fire Information for Resource Management System | Source of all hotspot data, country archives and area API | https://firms.modaps.eosdis.nasa.gov |
| MODIS Collection 6.1 Active Fire (MCD14ML), Terra and Aqua, 1 km | Long record 2000–2011 (harmonized) and calibration 2012–2025 | https://www.earthdata.nasa.gov/data/instruments/modis |
| VIIRS 375 m Active Fire, Suomi NPP (VNP14IMG) | Reference sensor of the harmonized series, 2012–present | https://www.earthdata.nasa.gov/data/instruments/viirs |
| VIIRS 375 m Active Fire, NOAA-20 (VJ114IMG) | Gap filling of S-NPP outages, map layer | https://www.earthdata.nasa.gov/data/instruments/viirs |
| VIIRS 375 m Active Fire, NOAA-21 (VJ214IMG) NRT | Current-year map layer | https://firms.modaps.eosdis.nasa.gov |
| FIRMS Area API (MAP_KEY), standard and NRT products | Current-year data (MODIS_SP/NRT, VIIRS_SNPP_SP/NRT, VIIRS_NOAA20_SP/NRT, VIIRS_NOAA21_NRT) | https://firms.modaps.eosdis.nasa.gov/api/area/ |
| LANCE (Land, Atmosphere Near real-time Capability for EOS) | Near-real-time processing behind the NRT products | https://www.earthdata.nasa.gov/data/tools/lance |
| FIRMS documentation and attribute descriptions (confidence, type) | Filtering rules | https://www.earthdata.nasa.gov/data/tools/firms/faq |

Other (non-NASA) resources: Natural Earth 1:10m admin-1 boundaries (public domain), CARTO /
OpenStreetMap base map tiles.

Acknowledgement: We acknowledge the use of data and imagery from NASA's Fire Information for Resource
Management System (FIRMS), part of NASA's Earth Science Data and Information System (ESDIS).
